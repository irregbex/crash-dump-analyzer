Cambios respecto de 1.3.0:
- crashSignature(): FNV-1a 32 bits sobre
  "tipo|código|módulo|versión|módulo+offset", con id "CDA-XXXXXXXX". Nota
  c.sameSig cuando la firma se repite.
- cxxExceptionType(): ThrowInfo -> CatchableTypeArray -> CatchableType ->
  TypeDescriptor (RVA en x64, punteros en x86); demangleTypeName();
  explicaciones cxx.* para 12 tipos estándar.
- fixFirst(): puntaje = 10 x caídas + 5 si es reciente (<= 90 días) + 2 si
  la confianza es alta - 8 si está resuelto. Los resueltos van siempre al
  final. Acciones fix.*.
- buildReportHTML(): un solo generador para "Export report (.html)" y
  "Print / PDF". CSS con alcance .rp; anonimizado antes del escape HTML.
- Dumps de demostración: DumpWriter, makeDump() y demoDumps(). Se generan
  en memoria y son válidos para la librería Python "minidump".
- I18N.de con 374 claves (tratamiento "Sie"); botón DE.
- analyzeInstruction() solo se ejecuta en fallos de hardware: AV/in-page
  con análisis completo; C000001D, C0000094, C0000095, C0000096,
  C000008C, C000008E y C0000090 solo con la instrucción.
